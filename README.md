# GTM in Motion — Enterprise landing page

A responsive, accessible, dependency-free landing page for a B2B GTM engineering and AI automation agency.

## Preview
Open `index.html` in a browser or run `python -m http.server 8000` inside this folder and visit `http://localhost:8000`.

## Deploy
Upload all files to any static hosting provider, or import the HTML/CSS/JS into your site builder. Point the domain's DNS to the hosting provider when ready.

## IMPORTANT before launching
1. The enquiry form currently opens a composed email to `hello@gtminmotion.com`; **it does not send data to a server**. Create that mailbox or replace the form with your approved secure form provider/CRM endpoint.
2. Add your privacy policy, cookie details (if using analytics or tracking), and legal company details as appropriate.
3. Review all messaging and platform examples before publication. No case-study figures, customer logos, certifications or partnerships have been invented.
4. Test forms, mobile layout, accessibility and domain/SSL after deployment.
5. The Google Fonts stylesheets require an internet connection; local fallback fonts are configured.

## Files
- `index.html`: website structure, SEO and content.
- `styles.css`: responsive visual design.
- `script.js`: mobile menu, dynamic year, mailto demo contact form.
- `favicon.svg`: brand icon.
